### Третья лабораторная
Самая объемная и сложная, по сути основа курса, в ней нужно было реализовать свой язык программирования по варианту.<br>
Для этого требовалось придумать синтаксис в соответствии с вариантом и реализовать на языке Python транслятор программ на данном языке программирования в машинный код.<br>
После чего нужно было реализовать симуляцию машины, которая выполняла бы получаемый машинный код.<br>
Таким образом нужно было сделать так, чтобы подаваемые на вход программы, написанные на созданном языке программирования, транслировались в машинный код и выполнялись, вместе с полным логированием состояния машины, которая выполняет машинный код.
