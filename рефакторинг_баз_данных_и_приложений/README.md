# Материалы по предмету "Рефакторинг баз данных и приложений (РБДиП)"

## 4 курс | 7 семестр | 2025 год

### Задание для курса

В данном курсе нужно было взять какую-нибудь крупную работу, например курсовую работу и зарефакторить в 3 итерации, перед этим составив план рефакторинга.

1.  Весь процесс рефакторинга необходимо разбить на три последовательные итерации. 
Необходимо выполнить анализ проекта, и сформулировать задачи (перечень рефакторингов) и цели, для чего вы это будете делать. Отправить это в виде отдельного документа, этот план мы согласовываем и далее - 

2. По завершении каждой итерации необходимо предоставить:
   - запись экрана с демонстрацией того, что функциональность проекта не нарушена после внесённых изменений.
   - отчет, содержащий diff для отслеживания изменений  описание внесенных изменений: что именно было изменено (какие части кода, схемы данных, архитектуры) и с какой целью (например, "упрощение логики", "устранение дублирования кода", "повышение производительности запроса", "разделение на модули для слабой связанности").
